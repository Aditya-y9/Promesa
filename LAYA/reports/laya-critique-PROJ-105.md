## Acceptance Criteria
1. System sends a welcome email immediately after user registration.
2. If the user has not completed their profile within 24 hours, send a reminder email.
3. If the user has not logged in for 3 days since registration, send a re-engagement email with a link to a getting-started guide.
4. All emails must include an unsubscribe link in the footer and respect the user's email opt-in preference.
5. Given the user has opted out of marketing emails, when any trigger event fires, then no marketing email is sent but transactional emails (welcome) are still delivered.
6. Scenario: Email bounces. Given the user's email address hard-bounces, when the system receives the bounce notification, then the user's email subscription status is set to 'bounced' and no further emails are sent.
