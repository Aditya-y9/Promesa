## Acceptance Criteria
1. Given I am viewing a dashboard with at least one widget, when I click the 'Export as PDF' button, then the system generates a PDF of the visible dashboard viewport.
2. The PDF file name should be 'dashboard-export-{current-date}.pdf'.
3. Given a dashboard with no data, when I export to PDF, then the PDF shows the dashboard layout with empty-state placeholders instead of erroring out.
4. The export must complete within 5 seconds for dashboards with up to 12 widgets.
5. Given the PDF generation is in progress, when I click 'Export' again, then the second request is queued and I see a toast 'Export already in progress'.
