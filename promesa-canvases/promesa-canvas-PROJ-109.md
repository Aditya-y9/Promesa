## AC as decision contract
- **[AC-1]** Scenario: Successful import. Given I upload a CSV file with headers 'email,role,department' and exactly 50 valid rows, when I click 'Import', then all 50 users are created, a success summary is shown ('50 users imported, 0 errors'), and a detailed import log is available for download.
- **[AC-2]** Scenario: Partial import with errors. Given I upload a CSV where 45 of 50 rows are valid and 5 have invalid email formats, when I click 'Import', then only the 45 valid users are created, an error summary is shown ('45 users imported, 5 errors — see error report'), and the system never creates a partially-written user record.
- **[AC-3]** Scenario: Empty file. Given I upload a CSV with only headers and no data rows, when I click 'Import', then the system rejects the file with message 'CSV file contains no data rows'.

- **[AC-5]** Maximum file size: the system accepts CSV files up to 10 MB; files larger than 10 MB are rejected with message 'File exceeds 10 MB limit' before any processing begins.
